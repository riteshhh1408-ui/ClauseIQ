# Agents and Skills

## Custom Agent

The ClauseIQ Document Agent is responsible for analyzing uploaded documents and helping users find reliable information from them.

The agent is designed to keep answers grounded in the provided document and avoid unsupported claims.

Location:

`.agents/clauseiq-agent.md`

## Custom Skill

The Document Grounding Skill provides a structured process for answering questions from uploaded documents.

It focuses on identifying relevant document content, grounding answers in that content, and avoiding guesses when information is not available.

Location:

`.skills/document-grounding/SKILL.md`
