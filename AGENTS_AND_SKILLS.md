# Agents and Skills

## Custom Agent

ClauseIQ Document Agent is responsible for analyzing uploaded documents and helping users find reliable information from them.

The agent is designed to keep responses grounded in the provided document and avoid unsupported claims.

File:

`.agents/clauseiq-agent.md`

## Custom Skill

Document Grounding Skill helps the application answer questions using information from uploaded documents.

The skill focuses on finding relevant document content, grounding answers in that content, and avoiding unsupported answers.

File:

`.skills/document-grounding/SKILL.md`

## Human Review
